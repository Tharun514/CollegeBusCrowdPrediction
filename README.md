# College Bus Crowd Prediction and Intelligent Route Management System

A full-stack web application for college bus management, occupancy monitoring, location tracking, and transportation operations.

## Technologies & Tools

Component                Technologies 

| Frontend       |Angular, TypeScript, HTML, CSS |
| Backend        | Java, Spring Boot, REST APIs |
| Database       | MySQL, Amazon RDS |
| Cloud &        | AWS EC2, Docker, Nginx |     
  Deployment
| Version        | Git, GitHub |
  Control 
| Development    | VS Code, Maven, npm |
  Tools 

## Deployment
- Frontend: Angular hosted using Nginx on AWS EC2.
- Backend: Spring Boot application running in Docker.
- Database: MySQL hosted on Amazon RDS.
- Source Control: Git and GitHub.

## Key Features
- Bus, route, student, and driver management.
- Bus occupancy and crowd monitoring.
- Bus location tracking.
- Attendance and complaint management.
- REST API integration.
- Cloud-based deployment.

## Architecture
**Angular → Spring Boot REST APIs → MySQL (Amazon RDS)**

Deployed on AWS EC2, with Nginx serving the frontend and Docker running the backend.
